# Boomy

Telegram Mini App crash game.

- `app/` — the Mini App, deployed to GitHub Pages on every push to `main`. Without a server it plays offline demo rounds.
- `server/` — the game server: rounds, wallet, test TON, admin panel and the support bot (see `server/README.md`).
- `docs/support-model.md` — the support model: FAQ, tickets to operators; the game rules use the same wording.
- `docs/backlog.md` — everything that still differs between the support model, the financial model and the code.
