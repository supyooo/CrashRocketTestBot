Как загрузить в @BotFather

  1. Имя, About, Description

    /mybots → бот → Edit Bot → Edit Name, Edit About, Edit Description. Тексты копируй кнопками выше, русская версия идёт по умолчанию.

  2. Аватарка

    Edit Bot → Edit Botpic → отправь выбранную avatar-*.png как фото.

  3. Картинка приветствия

    Edit Bot → Edit Description Picture → отправь welcome-ru.png как фото или welcome.gif как GIF.

  4. Кнопка меню

    Bot Settings → Menu Button → ссылка на игру и текст Играть.

  5. Экран загрузки и превью

    Bot Settings → Configure Mini App → Configure Splash Screen: иконка loading-icon.webp или loading-icon.svg, фон и шапка #12092A. Превью (preview-*.png) добавляются в визуальной версии BotFather (кнопка Open).

  6. Английская версия и команды

    Английские описания и меню команд подключим вместе с бэкендом: это одна строка кода на каждый текст. Добавлять команды раньше нет смысла, бот пока на них не отвечает.

Названия пунктов в @BotFather иногда немного меняются, но разделы остаются теми же: Edit Bot для профиля и Bot Settings для Mini App.
