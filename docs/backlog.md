Номера (`F-1`, `B-3`…) — чтобы ссылаться в задачах и коммитах. Закрытый пункт переносить в «Сделано» внизу.

## 6. Баги и техдолг

| № | Что | Где | Приоритет |
|---|---|---|---|
| R-1 | **Гонка выплат:** `settled()` / `drain()` не ждут выплат по авто-кэшауту. При деплое (SIGTERM) процесс может выйти до записи выплаты, а раунд уже закрыт — после рестарта игрок не получает ни выигрыш, ни ставку. Из-за этого «плавают» тесты `[postgres] auto cash-out…` и `max win caps…` | `server/src/game/engine.ts` | 🔴 |
| R-2 | Нет лимита суммарных выплат на раунд (при маленькой кассе один удачный раунд может её опустошить) | `server/src/game/engine.ts` | 🔴 (D-3) |
| R-3 | Тесты не запускаются в CI — только деплой на Pages | `.github/workflows/` | 🟠 |
| R-4 | У клиента нет тестов вообще | `app/` | 🟡 |
| R-5 | Версии клиента правятся руками в трёх местах (`APP_VER`, `version.json`, `?v=` у каждого скрипта) — легко забыть, и Telegram покажет старую копию | `app/index.html` | 🟡 автоматизировать |
| R-6 | Имя бота зашито в клиенте (`CrashRocketTestBot` в реферальной ссылке и как запасное для поддержки) | `app/screens.js`, `app/menu.js` | 🟡 брать с сервера (`BOT_USERNAME`) |
| R-7 | `ref_by` хранит голый Telegram id, а id пользователей — `tg:<id>` | `server/src/http.ts` | 🟡 учесть в F-8 |
| R-8 | Тестовый Postgres не стартует под root (права на `server/data/test-pg`) | `server/test/pg-helper.ts` | 🟡 |
| R-9 | Новые визуалы (сцена из `app/proto`, растровый медведь) не перенесены в игру; старая версия `app/v1/` лежит рядом | `app/` | 🟡 |
| R-10 | Нет описания процесса релиза и деплоя на Railway (`CLAUDE.md` / docs) | — | 🟡 |
